# Christening Invitation RSVP Web App

A warm, mobile-first invitation and RSVP experience created for a christening celebration.

## Project Goal

To turn a traditional event invitation into a thoughtful digital experience that feels personal, clear, and easy for guests to use on any device.

## Featured Work

- Video-led invitation landing page with an elegant, celebratory visual style
- Event details with ceremony and reception locations
- RSVP flow for attendance, primary guest details, and co-guests
- Confirmation modal with a private link for managing responses
- Self-service RSVP updates and withdrawals
- Responsive layouts, accessible form feedback, and server-side validation
- Google Sheets integration for organized RSVP tracking

## Built With

Next.js, React, CSS Modules, Google Apps Script, and Google Sheets.

The design pairs soft blush tones, warm neutrals, expressive typography, and small floral details to create an invitation that feels intimate without getting in the way of the RSVP flow.
